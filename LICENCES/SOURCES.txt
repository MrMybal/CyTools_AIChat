Not included: installed or downloaded on the user's machine
-----------------------------------------------------------

Python packages listed in app/requirements.txt (imgui-bundle, Pillow, numpy, pywin32, mcp
and their dependencies) are installed by pip into runtime/python. Each one carries its own
licence in its package metadata; the Options tab lists them.

llama.cpp (MIT) - https://github.com/ggml-org/llama.cpp
  The pinned release b11114 is downloaded from the Models tab into runtime/engines. Its
  CUDA build also brings NVIDIA CUDA runtime libraries under the NVIDIA CUDA Toolkit EULA:
  https://docs.nvidia.com/cuda/eula/index.html

Model weights and LoRA adapters are downloaded from the Models tab after the user accepts
each licence on the publisher's page. Their licences, sources and pinned revisions are in
app/llm-catalog.json and app/licenses.json.

Agent command lines (codex, claude, agy, opencode) are separate programs installed and
signed in by the user. This Tool starts them; it never redistributes them.

Speech environments (runtime/engines/stt and runtime/engines/tts) are created on request by
pip from app/requirements-speech-stt.txt and app/requirements-speech-tts.txt: PyTorch
(BSD-3-Clause, https://pytorch.org), transformers (Apache-2.0,
https://github.com/huggingface/transformers), coqui-tts (MPL-2.0,
https://github.com/idiap/coqui-ai-TTS), f5-tts (MIT, https://github.com/SWivid/F5-TTS) and
their dependencies, each with its own licence in its package metadata. The CUDA build of
PyTorch brings NVIDIA CUDA libraries under the NVIDIA CUDA Toolkit EULA. The window's runtime
also installs sounddevice (MIT, https://github.com/spatialaudio/python-sounddevice), which
ships PortAudio (MIT).

Speech models are downloaded from the Speech tab after the user accepts each licence:
  Phonon-2 (Fermion Research)              CC-BY-4.0 weights, Apache-2.0 code
    https://huggingface.co/FermionResearch/Phonon-2
  Parakeet TDT 0.6B v3 (NVIDIA)            CC-BY-4.0
    https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3
  XTTS-v2 (Coqui)                          Coqui Public Model License 1.0.0, non-commercial
    https://huggingface.co/coqui/XTTS-v2   (https://coqui.ai/cpml.txt)
  F5-TTS v1 Base (SWivid)                  CC-BY-NC-4.0, non-commercial
    https://huggingface.co/SWivid/F5-TTS
  F5-TTS French (RASPIAUDIO)               CC-BY-NC-4.0, non-commercial
    https://huggingface.co/RASPIAUDIO/F5-French-MixedSpeakers-reduced
  Vocos mel 24 kHz (charactr)              MIT
    https://huggingface.co/charactr/vocos-mel-24khz
Their pinned revisions and digests are in app/speech-catalog.json. The non-commercial
licences also cover the audio those models produce.
